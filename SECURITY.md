# Security policy

Report security problems in the lab harness privately through GitHub's
private vulnerability reporting: open this repository's
[Security tab](https://github.com/dukovo-os/lab/security) and choose
**Report a vulnerability**. Do not open a public issue about a
vulnerability before it is fixed.

Problems in Dukovo itself go to
[Dukovo's security policy](https://github.com/dukovo-os/dukovo/blob/main/SECURITY.md).
